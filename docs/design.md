## 地图规格

- Tiled：普通 `isometric`，非 staggered；40 列 × 40 行，地砖 128×64 px。
- 索引从 0 起，合法格子 `(col,row)` 均在 0–39；格心为 `(col+0.5,row+0.5)`。
- 逻辑行向下，列向右。投影后列轴斜向右下、行轴斜向左下。逻辑“北”为行减小，“东”为列增大。
- 格心投影：`screenX = originX + (col-row)×64`，`screenY = originY + (col+row+1)×32`。`originX` 由运行器统一确定，不在剧本中使用屏幕坐标。
- Tiled 等距对象坐标采用地图平面单位：每格按 `tileheight=64` 换算；点对象使用 `x=(col+0.5)×64, y=(row+0.5)×64`。运行器必须专门适配，不能直接把对象的 x/y 当屏幕像素。
- 当前 TMJ 是对象层规划模板，没有正式贴图、碰撞系统或运行时寻路网格；区域不自动代表可通行性。

### 地点与路线

地点编号是剧本接口；坐标集中放在布局数据里。移动阶段为：

`west_gate → handoff → flower_gate_stop → flower_gate → passage_entry → screen_detour → passage_exit → courtyard_west → courtyard_center → hall_steps → hall_door → daiyu_greet`

其中 `flower_gate_stop` 为下轿位置。穿堂插屏占列 13–14、行 20，路线从列 11 绕行。凤姐从 `feng_entry` 经 `feng_courtyard`、`feng_door` 到 `feng_meet`。

区域块用于布局评审。当前运行器使用区域与命名途经点生成简化通行网格，以 A* 绕过显式障碍；Routes 的 anchor_ids 是路线接口，折线几何暂为编辑器示意。正式美术阶段需要制作完整门洞与碰撞层；人物拥挤采用预留站位和短暂停等，首版不做复杂群体避障。跳过移动直接落到目标站位。

### Tiled 图层约定

当前模板包含：`Ground`（空图块层）、`PlanZones`（区域矩形）、`PlanBlockers`（插屏）、`Anchors`（格心地点）、`Routes`（折线）、`Cast`（初始人物点）。`Plan*` 和 `Routes` 是设计数据，运行时不直接显示。

美术阶段增加：`GroundDetail`、`BuildingBase`、`PropsBack`、`PropsFront`、`Roof`；保留运行时角色容器。高大建筑必须拆分，避免把整栋建筑作为单一深度对象。室内使用剖面，进入正房演出时隐藏对应屋顶。

已落地的最小版本：`PlanZones` 对象加 `indoor`（bool）标记室内地面，`Art` 对象加 `interiorZone`（string）声明这栋 `visibility=exterior` 的外观盖住哪个室内地面；有人站上该地面时外观自动隐藏，室内地面与陈设露出，人走开自动恢复。剧本 `roof` 动作仍是显式覆盖。人物立绘与 Q 版的镜像由 `design/character-facing.json` 的实测朝向驱动（`paintedFacing(actor, kind)`），不再使用全局左右集合。

### 朝向演出规则（整图镜像，模拟向后转）

镜像永远是**整张人物图**左右翻转（`setFlipX` / `scaleX(-1)`），不是只翻脸；翻错脸属于资产问题（见 `docs/production/art.md` 原告条目）。翻转条件由引擎的 `direction` 驱动，且不限于行走：

- 行走：每步按屏幕右（`col-row` 增大）更新 `direction`，整图镜像使人朝行走方向。
- 到达与入屋：移动结束（含"跳过移动"的瞬时分）与 `show` 时，新人面向场内最近的可见者，场内所有人转向新人——等距舞台没有逐场标注朝向，站立者的朝向从"谁站在哪"读出；屏幕左右即 `col-row` 增减方向。
- 停止与迁移：`direction` 停止后、跨场景/跨段落都不清空，人物保持最后朝向，直到下一次移动或入屋；所以第四回这类"只有屋里、没有屋外移动"的段落，同一角色在公堂与密室之间迁移时朝向连续，公堂里原告面朝老爷、老爷面朝原告。
- 对话立绘不在此规则内：讲话人朝文本、听众朝讲话人，仍只由 `paintedFacing(portrait)` 与位置决定。

## 人物与资源

首版角色：黛玉、贾母、邢夫人、王夫人、李纨、迎春、探春、惜春、王熙凤。辅助人物：引路婆子、通报丫鬟、平儿及轿夫群体，辅助人物配置仍需逐段核对。

初始场景只显示入府所需人物。室内角色在切入院内演出后揭示，三春按分镜入场，凤姐在画外对白后入场。地图上的角色初始点是布局占位，不意味着玩家一开始能看见全员。

| 资源 | 第一轮占位 | 正式美术建议 |
|---|---|---|
| 地面 | 3–5 种纯色菱形砖 | 石板、院土、台阶、室内地面 |
| 建筑 | 区域轮廓与门洞 | 垂花门、穿堂、正房、廊房，屋顶独立 |
| 地图人物 | 带姓名的色块或轮廓 | 四个斜向，待机 1–2 帧、步行每方向 4–6 帧 |
| 重点立绘 | 三名重点人物占位 | 黛玉、贾母、凤姐各 3–4 表情 |
| 其他立绘 | 姓名卡 | 按实际对白需要，每人至少 1 个表情 |
| 轿子 | 一个合成占位对象 | 轿体与轿夫群体可合成，交接阶段用淡出切换 |
| 环境小物 | 插屏、座椅占位 | 插屏、门帘、栏杆、树石等 |

人物建议使用透明画布 192×256 px，格心定位脚底，资源裁切后需保留 pivot 元数据；最终体感以人物脚下约一格、身体高约 1.5–2.5 个地砖高度为初稿目标，须与建筑试画比较。立绘建议先以约 1000×1600 px 画布试制。所有尺寸都是试画规格，不代表已确定产量与工期。

九名主要人物的四向待机各 1 帧、四向步行各 4 帧，最低约 180 帧；可复用骨架、分层或动画模板，但服饰与轮廓必须区分。辅助人物另计。先完成黛玉单人试画，再扩展资源。

## 界面与操作

桌面参考尺寸 1440×900；地图约占上部 62%，对话约占下部 38%，比例随实际立绘调整。底部包含立绘、姓名、正文、继续提示；记录、自动、设置放在对话区边缘。默认一个主要说话立绘，同屏多人物立绘后续再评估。

点击／空格推进对白，自动播放只在当前节点可推进时继续。地图移动时禁止连点穿越未完成指令；提供“跳过本段演出”，按顺序提交终态后停在下一个可读对白。手动拖动镜头后显示“回到剧情”；下一强制镜头指令生效前给出短过渡。点击地图人物打开关系说明，打开记录或设置时暂停剧情与自动播放。

关系说明以黛玉视角表达，图中亲属称呼与站位均须校订。首版将原文旁白和改编对白以类型区分，并可查看出处。

## 程序分工与阶段

原型采用 Tiled、Phaser、TypeScript、React、Vite，依赖已锁定于 package-lock.json。

- 地图数据维护地点与通行信息；角色数据维护资源、姓名、关系与显示状态。
- 剧情执行器是进度与演出状态的唯一控制方；Phaser 接收地图演出命令，React 接收对话与界面状态。
- 剧情指令先支持 `scene`、`show`、`hide`、`move`、`camera`、`say`、`pose`、`wait`、`parallel`、`checkpoint`、`end`。
- 对话记录、已读标记、自动播放和音量等设置独立于地图渲染层。
- 稳定节点保存版本号、章节、下一节点 ID、角色位置／可见性／姿态、屋顶状态与场景变量。演出中请求存档，延迟至下一个检查点提交。恢复时不重播已完成的对白与动作。

阶段一：占位素材跑通垂花门至贾母迎接。阶段二：补全首个片段与记录、跳过、存档。阶段三：替换手绘资源、校订文本、体验测试与性能检查。

## 验收

1. Tiled 中打开地图，确认 40×40 与等距方向，地点、站位、路线可选可编辑。
2. 运行原型中黛玉经过指定门与插屏旁路线，脚底位置正确，人物不穿墙。
3. 剧情到达指定节点才出现人物；凤姐先画外发声，再入场；无宝玉提前出现。
4. 室内外遮挡正确、角色不被整栋建筑意外盖住，镜头不被底部对白挡住。
5. 连点、自动播放、跳过与读档后人物和对白一致；打开记录时演出暂停。
6. 缺少地点或资源时给出可定位到节点 ID 的开发错误，不让剧情静默卡死。
7. 正式交付前，每条原文引用均能定位到底本；改写和补充设定有记录。

## 仍需通过原型确定

128×64 砖与人物的实际比例、目标电脑上的性能、角色四向动画成本、完整文本对应阅读时长。上述内容不影响当前布局评审，也不应在试画和技术验证前承诺最终效果或工期。

## 对话与行动的呈现（已实现）

- 对话框高度由容器控制：桌面 250px，手机 300px。同一屏宽下，换人物、换立绘、切换行动均不改变外框高度。
- 立绘使用绝对定位：讲话人在左，头肩越出上边框；在场人物在右，附人物切换按钮。旁白使用黛玉的视角立绘。其他人物尚使用占位图。
- 对白正文在固定区域内阅读，长文本独立滚动；控制条固定在底部，不随文本长度移动。
- 行动时立绘退场，显示动作标题及提示；镜头回到当前剧情，地图绘制当前剩余 A* 路线、流动光点、目标点及人物脚下光环。
- 暂停冻结地图和界面行动动效；系统减少动态效果设置会关闭循环动效，保留静态路径与标记。
