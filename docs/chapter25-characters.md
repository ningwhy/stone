# 第 25 回新出场两人 · 角色设计说明

《魇魔法姊弟逢五鬼　红楼梦通灵遇双真》这一回有两人新进 `cast`：
**马道婆**（`ma_dao_po`）与**彩霞**（`cai_xia`）。
癞头和尚（`monk`）与跛足道人（`taoist`）是第 1 回已登记的「一僧一道」，
本回「通灵遇双真」直接复用，不算新角色。

本文件说明两人的**设计依据、资产参数与本回叙事分工**。每人八段，结构一致：
身份定位 → 外形锚点 → 色彩标识 → 资产参数 → 朝向裁决 → 本回剧情功能 → 与同回角色的对照 → 边界。

## 马道婆 `ma_dao_po`

### 身份定位

宝玉**寄名的干娘**，常走荣府各院念佛化缘的庙里婆子。本回她是「魇魔法」一案的**主谋与执行人**：
先在贾母院劝供大光明普照菩萨、点海灯，再借鞋面为名进赵姨娘房，用「明不敢怎样，暗里也就算计了」
探出口风，收下五百两欠契与现银，掏出十个纸鬼、两个纸人，教赵姨娘写年庚八字掖到宝玉凤姐床上。
第 25 回是她第一次有台词、有行动。

底本依据（逐字）：
「就有宝玉寄名的干娘马道婆进荣国府来请安」；
「西方有位大光明普照菩萨，专管照耀阴暗邪祟」；
「伸手先去抓了银子掖起来，然后收了欠契」；
「把他两个的年庚八字写在这两个纸人身上，一并五个鬼都掖在他们各人的床上就完了」。

### 外形锚点

`features`（设计推定，非底本）：
**老妇；贾宝玉寄名的干娘、常走荣府各院念佛化缘的庙里婆子；面带精明世故，贪财（见银子便伸手掖起）**。

英文生图提示词给的落点是：约六十岁、窄脸、小而精明的眼、薄而抿的唇、算计的神情，
灰褐僧袍、深色佛珠、灰布头巾，语气是「and greedy and ingratiating」。
设计取舍：底本只给「寄名干娘」「庙里」「抓银子掖起来」三项行为证据，
所以形象走**老、瘦、精明、贪**一条线，不画成慈眉善目的诵经婆子——她一开口就卖海灯、一转身就卖魇魔法。

### 色彩标识

`color: 0x8a7f6d` · `css: #8a7f6d` —— **灰褐**。取僧袍与头巾的旧布色，压低饱和度；
与赵姨娘的暖褐 `#9c8878`、贾环的青灰 `#7d8a9c` 分开，地图上三人同框时不混。

### 本回剧情功能

15 句台词，横跨两段、两处场景：

- `c25-madaopo`（贾母院 `entry`）：`C25-042` 在 `passage_entry` 登场，随后五句推销海灯，
  「一天是四十八斤油」的排场话把贾母说动；
- `c25-mou`（赵姨娘房 `zhao_room`，**本回新建地图**）：`C25-051` 在 `door` 登场，
  先讨鞋面，再一步步撺掇；`C25-061`/`C25-070` 用 `anger` 效果压住两处关键台词，
  `C25-071` 收银、交货，段落到此收束。

她是本回「因」的一半：没有她的挑唆，赵姨娘的怨气只是怨气，不会变成魇魔法。
贾母院与赵姨娘房的两场戏一明一暗，人物从「化缘婆子」翻成「谋害主谋」，全靠她一个人的两次登场串起来。

### 边界

- 底本**没有**她的年龄、脸型、衣着的正面描写；60 岁、窄脸、灰褐僧袍、佛珠、头巾全是视觉设计推定，
  不可在剧情文案里写成原著事实。
- 「十个纸鬼两个纸人」在底本里写得明白，但第 69 节点后的「一并五个鬼」照录原文，
  不替底本做数目修正。
- 她与第 25 回的癞头和尚、跛足道人不是一类：后者是来解厄的「双真」，前者是施魇的凡人，
  三者虽都涉及佛道语汇，形象和色彩不能串。

## 彩霞 `cai_xia`

### 身份定位

王夫人房中的丫鬟，与**彩云是两个人**（`caiyun` 已在第 23 回登记）。
本回她的戏份集中在贾环抄《金刚咒》一场：众丫鬟都不答理贾环，只有她倒茶递过去，
悄悄劝他安分；宝玉要她拍著、拉她的手，她淡淡不答理、夺手不肯——
两句台词就同时交代了她「向贾环」与「拒宝玉」的立场，并直接点燃贾环推蜡灯烫宝玉的动机。

底本依据（逐字）：
「只有彩霞还和他合的来，倒了一钟茶来递与他」；
「彩霞咬著嘴唇，向贾环头上戳了一指头，说道：“没良心的！狗咬吕洞宾，不识好人心。”」；
「只见彩霞淡淡的，不大答理，两眼睛只向贾环处看」；
「彩霞夺手不肯，便说：“再闹，我就嚷了。”」

### 外形锚点

`features`（设计推定，非底本）：
**王夫人房中丫鬟；与贾环相好、心气高，对宝玉淡淡不答理、夺手不肯；有咬嘴唇、戳额头的小动作**。

英文生图提示词给的落点是：十六岁、鹅蛋脸、眉平眼定、神色矜持而略带轻蔑，
蜜桃与米白两件式丫鬟衣、素领、简单侧髻与小素簪。
设计取舍：底本只给了「咬嘴唇」「戳额头」「夺手不肯」三个动作和一个「淡淡的」神态，
所以形象走**有主见、不奉承、心气偏高**一条线，不做娇羞、不做媚态；
与「厚道本分」的彩云（第 23 回）在气质上明确分开。

### 色彩标识

`color: 0xd0a07a` · `css: #d0a07a` —— **暖蜜桃**。取衣着的蜜桃色，明亮但不过分华丽；
与彩云的雾蓝 `#8fa9c0` 形成「同房两丫鬟、一眼可分」的对立，
也与赵姨娘的暖褐 `#9c8878` 在明度上拉开。

### 朝向裁决

- 立绘 **左**（`visual-review`：视觉标志法鼻/嘴偏移 +0.014 / −0.038 互相矛盾；
  以 3×3 网格目视，三分之二侧脸朝左，右颊被头发遮住）
- Q 版 **左**（`visual-review`：检测器读不出脸；以左右参照 Q 版作 5×5 网格标尺，鼻尖落在眼中点偏左）

两人里只有彩霞是左朝向：她与上房里其他人说话时是「淡淡的、不答理」，视觉上让她的脸背离宝玉，
与剧情读法同向（但这是设计取向，不是从底本推出来的朝向事实）。

### 本回剧情功能

两句台词，一段场景（`c25-jiahuan`，王夫人上房 `wang`）：

- `C25-019` 在 `guest_seat` 登场（`show`），`C25-020` 劝贾环「你安些分罢」；
- `C25-022` 咬唇戳额头骂「狗咬吕洞宾，不识好人心」，配 `anger` 效果；
- 随后宝玉进来拉她的手，她在叙述里夺手不肯（第 17 段底本，逐字保留在相邻节点正文里）。

她的戏份短，却是贾环「心中越发按不下这口毒气」的直接导火索：
没有这一段「只有彩霞和他合的来」，后面推蜡灯就少了一层动机。

### 边界

- 底本**没有**她的年龄、脸型、衣着正面描写；16 岁、鹅蛋脸、蜜桃衣、侧髻全是设计推定。
- 「与贾环相好」出自底本「只有彩霞还和他合的来」与贾环「如今你和宝玉好，把我不答理」，
  不能写成「私定终身」之类超出底本的关系定性。
- 本回她**只在 `c25-jiahuan` 一段登场**；后面宝玉撒泼、烫脸、黛玉瞧伤等段落不要为了「凑戏」把她
  再 `show` 出来——底本没有写她在场。
- 与已登记的彩云（`caiyun`）是两人，文案与 cast 描述都要保持区分，不得合并。
