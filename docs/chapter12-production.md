### 穿堂屋壳为什么从列 12-18 挪到了列 14-20

`npm run map:framing` 报「lixiang-hall never in frame」。屋壳只在人还在屋外时画，它的脚被 `eave()` 钉在所属地块的南沿（行 19.5）。**等距投影里往西挪一列，屏幕上是同时往左和往上走**——原先摆在列 15 时，屋脚比站在小院 (17,25) 的人高出 240 px，屋脊比取景上沿还高 25 px，整座穿堂一次也没进过画面。把屋子挪到与院中站位同列（列 17），屋脚只高 176 px，从院里抬头就看得见檐口。

顺带修正的一处：列号由 `eave()` 保留，行号会被它覆盖，所以改行号是无效的——一开始我先试着把屋壳下移一行，跑完门禁照样报错。
