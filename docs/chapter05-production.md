### 踩过的坑（复用同一管线时必看）

1. **生成器会把地名读成建筑语境**。提示词写「太虚幻境的一颗仙珠」，两次都生成出**整座院落**（第一次带回廊，第二次把珠子画在院子正中）。改写成「游戏特效道具：一颗悬浮的发光魔法宝珠」并明确列出禁止出现的建筑元素后，才得到一颗球；最终从原图中按圆形 alpha 裁出珠体（r≈64，2.5px 羽化），弃掉周边院墙。
2. **单物件素材可能被多画配件**。`taixu-rock` 除太湖石外还带两块红褐小石（各占主体 11%），SAM 一并保留，游戏里每块山石旁都多一簇碎石。用连通域分析（`scipy.ndimage.label`，8 邻域）只保留最大连通块并重算锚点即可。其余素材的多连通域都是碎叶/火星级（<2%），无需处理。
3. **等距排布要按屏幕坐标算，不是按格子对称**。屏幕 `x=(c-r)*64`、`y=(c+r+1)*32`。想让两件东西**同屏高等距左右分列**，必须让 `c+r` 相等；想让一件东西**站在另一件身后**，要让它的 `c+r` 更小。石牌坊原本被更靠前（c+r 更大）的灵石整个盖住，改成 `(14,35)`／`(22,27)`（与牌坊 `(18,31)` 同 c+r=49）后左右对称。
4. **室内陈设必须落在正房的横向覆盖范围内**。`wang-hall` 的不透明墙体只占 sprite 包围盒约 2/3，其余是透明留边。陈设若摆到 `c-r ≥ 22`，就会从屋墙右侧露出来，变成「自鸣钟、多宝格坐在院子里」。把 9 件陈设收进 `c-r 14..18`、`row 2..5`，并把正房从 0.85 放大到 0.95，屋顶不掀时全部藏在墙后，掀开后正好铺满屋内。
5. **细长素材的实心率天然偏低**。`alpha-report.json` 要求 `solidAlpha250Ratio ≥ .89` 且 `faintAlphaRatio < .07`；瓶花细枝、椅子细腿这类素材缩放后边缘多为 16–210 的半透明像素，会被判失败。`calibration.json` 支持逐素材覆写 `solidAlphaThreshold` / `alphaFloor`（`taixu-vase` 用 60/30，`wang-chair` 用 120/8）。
6. **地坪只铺了 0..40 的菱形底色**。香闺在 row 3、警幻院在 row 5，镜头贴着地图北缘，屏幕右上会露出页面米色底。已在 `src/MapScene.ts` 把底色矩形扩到 `-16..56`（同色，无缝）并给外圈补同款纸纹。

## 第三轮：陈设成套摆放（2026-10-28）

上一轮把素材换成了专属的，但反馈是「丰富是够丰富了，也够乱了，就是把素材胡乱摆了一通」。查下来不是审美问题，是三条机制问题，逐条修：

### 一、没有地，家具只能浮着

`src/MapScene.ts` 的 zone 铺装对 `myth/dream/ruins` 三个主题是 `continue` 跳过的——太虚幻境因此只有一片纯色底，柜、案、椅、炉全像贴纸放在空白纸上。新增根属性 `terraces`（见 [地图构建](production/maps.md)）与 `MapScene.terrace()`：带台帮的台基（court）与石条甬路（path）。

`c5_taixu` 现在七块台：香闺、警幻院、薄命司、左右配殿、宫门前庭、石牌坊台，相邻两块各叠进对方一格，由远到近绘制，接缝处后画的台帮自然成了一道踏跺。所有 Art 另加了一条脚线接触阴影（排序在自身 sprite 之下、近处道具仍能盖住它），`pearl` 与整栋建筑除外。

### 二、按整数格摆小件，等于把椅子甩出桌外

一格是 `(±64, ±32)` 像素，一张案 146px 宽。椅子填「相邻一格」，屏幕上就离开案沿半张桌子——宴席看着不像席面，香闺的两把椅子悬在空处。

两个构建脚本各加了一个 `at(c, r, dx, dy)`，把屏幕像素偏移换算回格坐标（`dc = dx/128 + dy/64`、`dr = dy/64 - dx/128`），一处先定落点、其余件按像素相对它摆。改完后：宴席四椅贴案两沿、炕桌手炉茶盘落在炕面上、多宝格与自鸣钟沿东墙一字排开。

### 三、布景之间没有隔，邻室家具探进画面

薄命司与警幻院的中心在屏幕上只隔 358px，两屋的家具直接叠在一起。三处调整：

- 薄命司从 `(18,11)` 西移到 `(12,11)`，与警幻院拉开到 768px，也把「宫门→配殿→薄命司」的走位从折返改成顺路；
- 香闺绣阁从 `(26,3)` 东移到 `(31,2)`，与宴席拉开到 1100px，西侧用两株玉树作花木隔断；
- 撤下全部 `taixu-pearl` 陈设：那颗珠子是高饱和洋红发光球，在淡彩里读作游戏特效，且「绛珠」本是仙草不是珠子，待按仙草重生成后再摆。

### 顺带修掉的两处结构性缺陷

- **薄命司 40 个节点的镜头全停在宫门上。** C05-031..070 的 `focus` 一律 `gate_outer`，读者读判词、翻册页时画面还对着「孽海情天」四个字。改为按走位推进：35–37 配殿、38–44 大橱、45–70 册页案；`c5-banquet` 76 节点起落到席面。
- **左配殿原本是空台。** C05-035..037 宝玉与警幻在 `hall_left (10,20)` 停四个节点看匾额对联，那里一件陈设也没有。补了台基与同式的屏门、灵石一对、玉树一双（左右对称是原著「两边配殿」的意思）。另修 `visibility=interior`：室内陈设在屋顶盖着时不得站到屋墙外（凤姐院的多宝格、自鸣钟曾有一半露在院中）。

## 总览标签：第五、六回不再落回荣国府（2026-10-28）

`App.tsx` 的视图切换原来是「`chapter<3` 给本回行迹，其余一律荣国府总览」。第三、四回在府里，这条规则
看不出问题；第五回整回在**宁国府**（会芳园、秦氏卧房）、**太虚幻境**、**迷津**，第六回在**刘家庄**，

荣国府平面图，会芳园在图上不存在。

改成按「这一回是否在府内」判断：`insideEstate = chapter===3 || chapter===4`，其余走 `JourneyMap`。

`JourneyMap` 原来只认 `prequel-maps` / `chapter04-maps` / `travel-maps` 三份设计表，第五、六回没有设计表，

- 名字：设计表 `name` → TMJ `title` → 节点自己的 `place`，逐级回退；
- 缩略图：设计表里 `estate-*` 的大件 → 该图的特殊件（`lin` 用 `river-boat`、`dream` 用 `crimson-pearl`）
  → **该图全场最高的那件陈设**。最后这条是给没有设计表的图用的：三张卡片因此分别拿到会芳园的门、
  太虚幻境石牌坊、迷津的荆榛，而不是三张一模一样的补天石。
