# 第 24 回新出场八人 · 角色设计说明

《醉金刚轻财尚义侠　痴女儿遗帕惹相思》这一回有八个新角色进 `cast`：
贾芸、小红、倪二（醉金刚）、卜世仁、香菱、秋纹、碧痕、鸳鸯。

本文件说明这八人的**设计依据、资产参数与本回叙事分工**。每一节的结构一致：
身份定位 → 外形锚点 → 色彩标识 → 资产参数 → 朝向裁决 → 本回剧情功能 → 与同回角色的对照 → 边界。

三条通用口径：

1. **`features` 是设计原文，不是原文引文。** 它是「脸型；眉眼；鼻唇；体态」四段式加一句身世背景，
   凡属原创解释的部分不冒充原书记载。底本原话另在每节「底本依据」里逐字给出。
2. **立绘与 Q 版是两张独立图。** 立绘高 600、Q 版高 116，各自标 `faceBox`（在**最终 PNG 坐标**里）；
   Q 版另带 `bodyCompress`（`split` + `factor: 0.64`）做大头小身。**立绘与 Q 版不可互推**——
   本项目实测两者朝向一致率仅 76%，朝向一律以 `design/character-facing.json` 为准。
3. **`color` / `css` 是身份标识色**，一一对应，供地图上的角色标记与占位立绘取色；
   有手绘立绘后占位路径不再启用，但配色仍保留在 `cast` 里作为身份锚点。

八人共同的资产规格：立绘高度一律 600、Q 版高度一律 116（缩放按 `height` 而非 `width`，
见 `docs/production/art.md`「新增人物必须走同一条管线」第三条）；seed 段为 10234120~10234190，
Q 版 seed = 立绘 seed + 1。

## 贾芸 `jia_yun`

### 身份定位

荣国府后廊上住着的五嫂子的儿子，「最伶俐乖觉」。**本回主线人物**——求贾琏谋差未得、
转向母舅卜世仁赊香不成、反得醉金刚倪二仗义借银，最后靠奉承凤姐谋得种树工程。
前十三回只在旁白里被提到过一次，本回是他第一次真正有台词、有行动的人。

底本依据：「他是后廊上住的五嫂子的儿子芸儿」「容长脸，长挑身材，年纪只好十八九岁，
生得著实斯文清秀，倒也十分面善」「原来这贾芸最伶俐乖觉」「贾芸道：‘十八岁。’」

### 外形锚点

`features`：**青年长脸；眉疏目秀；鼻梁挺直；身量颀长**，十八岁，荣国府后廊上住着的
五嫂子之子，生得斯文清秀、极伶俐乖觉。

设计取舍：底本给的是「容长脸」「长挑身材」「斯文清秀」三项，全部落在**瘦高清俊**这一条线上，
所以面部定为窄长脸、眉疏而不浓、眼秀而不媚、鼻梁挺直，通篇不设胡须、不加须髯，
避免与「市井／中年」类角色撞形。

### 色彩标识

`color: 0x7d94ab` · `css: #7d94ab` —— **青灰蓝**。取「文秀清瘦、不涉市井」的冷色系；
与同回卜世仁的暗橄榄（`#7a7266`）、倪二的赭褐（`#8a6f52`）在色相上明确分开三人。

### 朝向裁决

- 立绘 **右**（`vision-landmark-geometry`，noseOffset 0.1217 / mouthOffset 0.0885，3 票一致）
- Q 版 **右**（`visual-review`：检测器在任何裁切都读不出脸，以 `cui_lv-chibi`（右）与
  `jia_rong-chibi`（左）作双向标尺目视判读，鼻嘴落在眼中点、极轻微右偏）

### 本回剧情功能

**唯一的贯穿性视点人物**，12 次 `show` 覆盖 8 个场景：宁荣街（`west_corner`）→ 贾琏院（`yard`）
→ 香料铺街面（`street`）→ 三街六巷（`lane`）→ 贾芸家（`street`）→ 凤姐院外（`back_gate`）
→ 绮霰斋（`gate`）→ 荣国府门前（`outside`）→ 还银（`lane`）→ 怡红院窗下（`window_place`）。

他的 58 句台词占本回 8 人台词总数的近一半，是唯一贯穿「求告—落难—解围—谋差—结帕」五段的人。
功能上有三处刻意设计：

1. **「最伶俐乖觉」必须体现在台词上，不能只写在介绍里。** 所以他见宝玉就说「摇车里的爷爷，
   拄拐的孙孙」，对卜世仁讲「巧媳妇做不出没米的粥来」，对倪二讲「我见你所相与交结的，
   都是些有胆量的有作为的人」——三处都是**用对方的语言反制**，这是「伶俐」的文本证据，
   不是作者旁白里的一句评语。
2. **他在倪二面前要「半推半就」。** 底本写他心里「不如借了他的，改日加倍还他」，
   台词上却先夸倪二是「好汉」再「怎敢不领」。剧本照录这种**心里想与嘴上说的错位**，
   这是他区别于一般「被欺负后感恩」角色的关键。
3. **他两次见凤姐都用「奉承」推进剧情**（C24-187~C24-205 献冰麝、C24-254~C24-273 求差事），
   且第二次明说「婶子辜负了我的孝心」——把第 24 回的「机变」主题落在他一个人的言行上。

### 与同回角色的对照

- **对卜世仁**：外甥求舅赊账，卜世仁推脱。二人色相一冷一暗，设计上必须一眼能分清「斯文」
  与「刻薄」，不能都做成清瘦长脸。
- **对倪二**：一个是「最伶俐乖觉」，一个是「泼皮无赖却因人而使，颇颇的有义侠之名」。
  底本把两人写成**同一副身量的对照**——所以倪二必须壮（方脸、络腮胡、粗壮），
  贾芸必须瘦（长脸、颀长）。壮瘦对比是这一段的读法基础。

### 边界

**贾芸之母不上台、不入 `cast`**（设计推定 D7）。底本写她「自在炕上拈线」「便问那去了一日」，
只有叙述、没有台词。图上留炕位锚点 `mother`，人物不登记——进 `cast` 就得配一整套美术资产，
不值当。同理不入 `cast` 的还有**卜家娘子、银姐、倪二娘子**（D4）。

## 小红 `xiaohong`

### 身份定位

本姓林，小名红玉，因「玉」字犯了黛玉宝玉，便都叫她小红。**荣国府中世代的旧仆**之女，
父母现管各处房田事务；年方十六，分在大观园时进了怡红院。底本写她「倒也清幽雅静」。

本回她是「痴女儿遗帕」这条下联的落点：**开场在绮霰斋替宝玉挡驾，结尾在怡红院窗下被贾芸拾帕**。

底本依据：「原来这小红本姓林，小名红玉，只因『玉』字犯了林黛玉、宝玉，便都把这个字隐起来，
便都叫他『小红』」「原是荣国府中世代的旧仆」「这红玉年方十六岁，因分人在大观园的时节，
把他便分在怡红院中，倒也清幽雅静」「这红玉虽然是个不谙事的丫头，却因他有三分容貌，
心内著实妄想痴心的往上攀高」。

### 外形锚点

`features`：**少女瘦长脸；眉细目灵；鼻小唇薄；一头黑鬒鬒的头发挽着髻**，十六岁，
容长脸面、细巧身材、十分俏丽干净。

设计取舍：底本用「容长脸面、细巧身材、十分俏丽干净」三句形容她，其中**「黑鬒鬒的好头发」**
是唯一的硬件描写，所以发型是设计的重点——发量厚、梳得紧、挽一个利落的髻，
不做少女常见的散辫或双环。眉眼取「细而灵」，与香菱的「弯而秀」拉开（见下节对照）。

### 色彩标识

`color: 0xc0856e` · `css: #c0856e` —— **灰玫瑰陶土色**。对应底本「穿著几件半新不旧的衣裳」，
是半新不旧、旧而干净的暖灰调；与香菱的淡藕粉（`#c9a8b0`）在明度与饱和度上都不同，
两人同时在场时不会糊成一片。

| 尺寸 | 151×600 | 54×116 |
| anchor | `[64.714, 599.445]` | `[27.169, 115.879]` |

| seed | 10234130 | 10234131 |

### 朝向裁决

- 立绘 **右**（`vision-landmark-geometry`，noseOffset 0.4469 / mouthOffset 0.3068，3 票一致）
- Q 版 **右**（`visual-review`，同 `cui_lv-chibi` / `jia_rong-chibi` 双向标尺）

### 本回剧情功能

3 次 `show`、17 句台词，分两处：

1. **绮霰斋挡驾**（C24-230 起，`door` 锚点）。底本写她初见贾芸「便抽身躲了过去」，
   后来才「下死眼把贾芸钉了两眼」，末了「那丫头冷笑了一笑」。剧本照录这个**态度的三段变化**
   ——躲 → 盯 → 冷笑，正对应底本「说话简便俏丽」与「有心攀高」两处交代。
2. **怡红院递茶与遗帕**（C24-303 `window_place`、C24-331 `cui_lv_place`）。
   底本写宝玉打量她「一头黑鬒鬒的好头发，挽著个䰖，容长脸面，细巧身材，却十分俏丽干净」，
   剧本把这段描写原样放在 C24-307 作叙述，让**外形描写落在她本人登场的那一句上**。

她的功能是「让贾芸这条线闭合」：宝玉没空见贾芸 → 她替宝玉传话 → 她听懂了贾芸的意思
→ 最后在窗下拾帕。**她既是挡驾的人，也是结局的人**，这是底本自己的安排，不是编剧加的。

### 与同回角色的对照

- **小红 vs 香菱**：两人都是少女、都在大观园、都是「俏丽」一路。小红是**瘦长脸 + 眉细目灵 +
  鼻小唇薄**，香菱是**圆脸 + 眉弯目秀 + 唇点胭脂**。小红胜在清瘦利落，香菱胜在圆润妍丽。
  两人的色彩（陶土玫瑰 vs 淡藕粉）与发型（紧挽髻 vs 白花簪）也都拉开。
- **小红 vs 秋纹、碧痕**：同属怡红院丫鬟，但小红是「世代旧仆」出身、往上攀高的心思；
  秋纹碧痕是「看着宝玉不属意，早就心里嘀咕」的一路人。三人同台（C24-323 起同在怡红院），
  靠**体型**分层最有效：小红纤细（身量纤细）、碧痕纤细（身段纤细）、秋纹结实。

### 边界

小红**不入账簿**（`design/ledger.json` 54 笔中无此人）——本回她没有「获得/给出」任何物件，
账簿只记物的转手。她与贾芸的帕子在本回是「遗帕」而非「定礼」，
按底本「要知端的，下回分解」，**不预记信物**。

## 倪二 `ni_er`（醉金刚）

### 身份定位

紧邻贾家的街坊泼皮，「专放重利债，在赌博场吃闲钱，专管打降吃酒」，人称「醉金刚」。
本回他同时是**反派底色**与**义侠化身**——底本明写「素日倪二虽然是泼皮无赖，却因人而使，
颇颇的有义侠之名」。

底本依据：「原来这倪二是个泼皮，专放重利债，在赌博场吃闲钱，专管打降吃酒」
「这三街六巷，凭他是谁，有人得罪了我醉金刚倪二的街坊，管叫他人离家散」
「若说怕利钱重，这银子我是不要利钱的，也不用写文约」。

### 外形锚点

`features`：**壮汉方脸；浓眉阔眼；络腮胡；身量粗壮**，喝醉了的市井泼皮，放重利债的，
街坊人称「醉金刚」。

设计取舍：这是八人里唯一的**胡须角色**。络腮胡是「市井粗汉」最快读出来的符号，
也让他的方脸+阔眼在剪影层面就能与所有清秀系角色分开——本回同场的贾芸、卜世仁全是窄长脸，
倪二必须是方的、厚的、有毛的。服装定为「破旧短褐、敞开胸口、额扎布带、腰挂鼓胀皮囊」，
后两项对应底本「正从欠钱人家索了利钱，吃醉回来」。

### 色彩标识

`color: 0x8a6f52` · `css: #8a6f52` —— **深赭褐**。市井、酒、皮革的暗调；
与贾芸的青灰蓝、卜世仁的暗橄榄在饱和度上拉开（倪二最暖最浊）。

### 资产参数

| 项 | 立绘 | Q 版 |
| --- | --- | --- |
| 尺寸 | **270×600** | **94×116** |
| anchor | `[169.699, 599.458]` | `[67.192, 115.917]` |
| faceBox | `[84, 19, 135, 66]` | `[16, 18, 62, 52]` |
| seed | 10234140 | 10234141 |
| bodyCompress | — | `{split: 394, factor: 0.64}` |
| hash | `ae167f08e0cf` | `c6a86d16ed50` |

**他是八人中唯一「宽大于高比」的极端体型**：立绘宽 270、Q 版宽 94，都是八人最大。
按 `height` 缩放时他自然显得比其余七人横向膨胀一圈——这正是要的效果：
底本写他「抡拳就要打」「一把抓住」，体型必须压得住场面。
Q 版 `faceBox` 只有 52 高（八人最低），因为络腮胡把下巴线吃掉了。

### 朝向裁决

**本回唯一立绘与 Q 版朝向不一致的人**：

- 立绘 **左**（`visual-review`：Vision 地标拟合在所有可用裁切里都把鼻嘴落在眼中点左侧）
- Q 版 **右**（`visual-review`：检测器读不出脸，目视判读偏右）

**运行时以 `design/character-facing.json` 为准，两者各自生效**——`src/Portrait.tsx` 按资产键查朝向，
`src/MapScene.ts` 用 `sprite.setFlipX()` 让 Q 版朝行进方向反的方位。
设计文档记录这一处分歧，是为了后续重标时不至于当成 bug 抹平。

### 本回剧情功能

2 次 `show`（均在 `ni_er_lane` 的 `drunk` 锚点）、20 句台词，全部集中在
`c24-nier`「三街六巷 · 醉金刚义侠」一段。

他的台词结构是**四段递进**，剧本照录底本的顺序，不做压缩：

1. **认错人起手**：「臊你娘的！瞎了眼睛，碰起我来了」→ 认出是熟人立刻「我该死，我该死」。
2. **摆出地盘**：「这三街六巷，凭他是谁，有人得罪了我醉金刚倪二的街坊，管叫他人离家散！」
3. **戳破贾芸的顾虑**（本段的戏眼）：他不光说「我不要利钱」，还反问「也不知你厌恶我是个泼皮，
   怕低了你的身分」——**他主动说出对方可能嫌弃自己的身份**。
4. **用「相与交结」定义义气**：贾芸说「我见你所相与交结的，都是些有胆量的有作为的人」，
   他立刻接「既说『相与交结』四个字，如何放帐给他，使他的利钱！」——**放高利贷的人
   自己宣布不收利就不算放帐**，这是全回最锋利的一处反讽。

另外两处设计要点：
- **他坚持不写文约**（C24-162「我便不写罢了，有何著急的」），并把「写文契」说成对义气的亵渎。
  底本原话照录，与「放重利债」的人设形成最强反差。
- **他借酒劲脱身**，走时趔趄（`趔趄著脚儿去了`），仍留一句「叫他们女儿明儿一早到马贩子
  王短腿家来找我」——**给本回的「还银赎义」段留下接口**。

### 与同回角色的对照

- **倪二 vs 贾芸**：本回的核心对照，见贾芸节「壮瘦对比」。
- **倪二 vs 卜世仁**：一富一穷、一放债一卖香料、一讲义气一讲合同。
  卜世仁「立了合同，再不许替亲友赊欠」，倪二「既说『相与交结』四个字，如何放帐给他，
  使他的利钱」——**两人对「钱与情」的态度完全相反，所以一个精瘦、一个粗壮；
  一个冷脸发青、一个涨脸发红**。

### 边界

**倪二娘子不上台、不入 `cast`**（设计推定 D4）。底本只有贾芸捎信一句「叫他他们女儿明儿一早到
马贩子王短腿家来找我」，指的是倪二的**女儿**，全回无一句台词，不登记。

## 卜世仁 `bu_shi_ren`

### 身份定位

贾芸的母舅，现开香料铺，「惯会推脱」。本回他扮演贾芸的**第一次挫败**——

## 鸳鸯 `yuan_yang`

### 身份定位

贾母房里的**首席大丫头**，容貌标致、进退得体。本回她是全回第二段的主角，
演的是宝玉「涎皮讨胭脂」一场——**本回唯一一场纯粹的调情戏**。

底本依据：「果见鸳鸯歪在床上看袭人的针线呢」「鸳鸯穿著水红绫子袄儿，青缎子背心，
束著白绉绸汗巾儿，脸向那边低著头看针线，脖子上戴著花领子」「其白腻不在袭人之下」
「好姐姐，把你嘴上的胭脂赏我吃了罢」「袭人，你出来瞧瞧。你跟他一辈子，也不劝劝，
还是这么著」。

### 外形锚点

`features`：**少妇长脸；眉弯目大；肤色白腻；身量修长**，贾母房里的首席大丫头。

设计取舍：底本这一段是**全回唯一一次给了完整服装细节的新角色**——
「水红绫子袄儿，青缎子背心，束著白绉绸汗巾儿，脖子上戴著花领子」四样俱全，
所以她的服装按底本逐样落实：水红绫袄 + 青缎背心 + 白绉绸汗巾 + 花领子。
另有「其白腻不在袭人之下」，故定为**白腻肤色**（八人中唯一以肤色为设计要点的）。
体态「身量修长」，且她是首席大丫头，在贾母房里当值，**气度必须压得住场面**，
所以眉弯目大（不细眉、不粗眉），与秋纹的「眉粗眼大」只差一个粗细，方向却是反的。

### 色彩标识

`color: 0xc4574f` · `css: #c4574f` —— **水红**。**直接取自底本「水红绫子袄儿」**，
是八人中唯一**色彩有底本明文依据**的人。饱和度明显高于香菱的淡藕粉与小红的玫瑰陶土——
她是当值的首席大丫头，颜色要出挑。

### 本回剧情功能

1 次 `show**（`yihong` 的 `xiren_kang` 锚点，C24-012）、4 句台词，整段在 `c24-yuanyang`
「怡红院 · 鸳鸯与胭脂」。

她有两段表演，剧本照录：

1. **公事公办**（C24-013~C24-014）：「你往那里去了？老太太等著你呢，叫你过那边请大老爷的安去。
   还不快换了衣服走呢。」
   ——她是**唯一带着「公事」进怡红院的人**，一句话就把宝玉从闲处拽走。
   这一段用 `yihong` 图的 `xiren_kang` 锚点（设计推定 D2：底本写「宝玉因被袭人找回房去，
   果见鸳鸯歪在床上看袭人的针线」，故放在怡红院外间）。
2. **被调戏后的反击**（C24-022）：「袭人，你出来瞧瞧。你跟他一辈子，也不劝劝，还是这么著。」
   ——**她不羞不恼，反手把袭人拉出来做见证**。这是贾母房首席大丫头的做派：
   不接招，但也不失态，用规矩压场。

她的服装描写（C24-014 叙述）原样落在她自己登场那一句：
「穿著水红绫子袄儿，青缎子背心，束著白绉绸汗巾儿，脸向那边低著头看针线，脖子上戴著花领子」——
**让读者第一眼看见的鸳鸯就是底本写的那身鸳鸯**。

### 与同回角色的对照

- **鸳鸯 vs 香菱**：见香菱节「一柔一丽」。
- **鸳鸯 vs 袭人**：底本亲口比过——「其白腻不在袭人之下」。剧本因此让鸳鸯的肤色设计
  与袭人同级（白腻），但**气度更外放**：袭人是内敛的鹅黄/杏色系，鸳鸯用水红 + 青缎的撞色，
  配花领子与金簪。袭人是「服侍」的分寸，鸳鸯是「当值」的派头。

### 边界

鸳鸯**不入账簿**（本回她没有物的转手）。她的胭脂是宝玉**讨**的、不是她**给**的，
底本里她并未递出任何物件——按账簿「获得/给出」的记法，不构成一笔。

## 重建与校验

```bash
# 资产登记（新增或改动角色设计后必跑；只重写新角色的条目）
python3 scripts/rebuild_new_character_manifest.py
# 注意：该脚本会重排 manifest 缩进。只想改 features 时用定点替换，
#       避免产生上千行无关 diff。

# 朝向裁决改了就必须重跑这两个脚本
python3 scripts/build_facing.py
python3 scripts/build_facing_doc.py

# 常规验收链
npm run check:content && npm run check:anchors && npx tsc --noEmit && npm test
```

**改 `art/identity/character-designs.json` 的 `features` 时**，必须同步四处：
设计表 → `public/assets/rongguo/manifest.json` 的两个资产块（`<id>-portrait` / `<id>-chibi`）
→ `src/story.ts` 的 `cast` 描述 → 相关 `scripts/gen_chNN_characters.py` 的注释。
**只改设计表不改 manifest，运行时读到的仍是旧文案**——这是第 24 回修香菱身世时踩过的路径。
