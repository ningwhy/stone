## 原著约束与设计推定

- 明示证据：
  - 刘姥姥是狗儿的岳母（女婿之母），原是积年老寡妇，靠两亩薄田度日。
  - 狗儿家与王家连宗，认作侄儿；周瑞家的丈夫周瑞当年争买田地时多得狗儿之力。
  - 狗儿让刘姥姥找的是**太太的陪房周瑞**（周瑞家的之夫），原文作「你竟带了外孙子孙儿，先去找陪房周瑞……这周瑞先时曾和我父亲交过一件事，我们极好的」。周瑞本回**不在府中**，是门人指点说「那周大爷已往南边去了……他娘子却在家」，所以刘姥姥实际找到的是周瑞家的。
  - 刘姥姥此行的目的，原文是「原是特来瞧瞧嫂子你，二则也请请姑太太的安」，核心动机是「谋事在人，成事在天」与「我倒替你们想出一个机会来」。
  - 路线：狗儿家 → 宁荣街荣府**大门石狮子**（不敢过去）→ **蹭到角门**，问门人 → 门人指点「绕到后街上后门上去问」→ 后门 → 周瑞家院 → 倒厅 → 贾琏院（先遇平儿）→ 堂屋看自鸣钟 → 凤姐上房 → 东屋吃饭 → 仍从后门去。
  - 凤姐实际给的：二十两银子（昨日王夫人给丫头们做衣裳的）+ 一吊钱（雇车钱）。刘姥姥另给周瑞家孩子一块银子买果子，被拒。
  - 凤姐对刘姥姥的称呼是「你侄儿」，周瑞家的当面数落她这话。
  - 刘姥姥进凤姐院先看见自鸣钟（「堂屋中柱子上挂着一个匣子，底下又坠着一个秤砣般一物」），是荣府内少见的西洋器物。
