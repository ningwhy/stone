### 暂停断言的修正

冒烟测试原先用 Playwright 的元素截图比较暂停前后的画面，偶发失败。逐层取证后确认这不是产品缺陷：

- 页面内直接读取 canvas 像素：暂停期间哈希恒定、0 像素差异；
- 相机 `scrollX` / `scrollY` / `worldView` 在暂停后完全冻结；
- `locator.screenshot()` 会抖动，但用整数坐标的整页 `clip` 截图连续四帧完全一致；
- 手动 `loop.sleep()` 停掉渲染循环后，元素截图立刻稳定。

原因是 Phaser 暂停期间仍在每帧重绘同一内容，而元素截图路径会强制 canvas 层重新光栅化，暴露出 GPU 纹理重上传的舍入微差；画面内容本身未变。测试改为在页面内比较 canvas 像素，并做了双向对照：运动时哈希不同、暂停时相同、恢复后再次不同，确认该断言不是恒真。
