### 新增定向验收脚本 `tests/chapter18.mjs`
它守住四件容易悄悄坏掉的事：
1. **十六段全部能推进**，且每段落点与设计数据一致；
2. **每段的场景都在声明的场景表内**，七张复用图都被用到（哪张没被走到，就是某段场景写错了）；
3. **目录搜索能搜到本回正文**，且命中卡片确实属于 `c18-*`；
4. **封底是全书终幕**——第十九回还不存在，封底必须显示「全书至此」而没有「开启下一回」，
   否则那个按钮会把读者推进一个不存在的回目。

另有一项**离线**校验在脚本末尾：把 135 个节点的正文去掉标点后逐条在底本里查，
**一条都不许不在底本**——这是「底本切片式生成」这条纪律的机器化守门。

写这个脚本时踩到的三个坑（都记在 `tests/lib/` 的注释里）：
- **TOC 是原生 `<dialog>`**，`onCancel` 把 Escape 拦掉了 → 只能用它自己的「关闭弹窗」按钮关。
- **全书最后一个节点的标签固定显示「终幕」**，不是节点 id（`src/App.tsx` 的既有行为）。
- **封底只在「自然推进一步」时翻出来**（`leafTrigger` 要求 `advanced`），`seek` 跳读不翻页 →
  想测封底必须停在末节点的前一句再自然走一步。
