# 第一个片段：入府至凤姐迎客

状态：演出结构草案，非定稿剧本。所有对白与旁白样例均为展示改写；原文、出场顺序和辅助人物应在选定第三回底本后校订。动作秒数只计无阅读等待的演出部分，不能据此声称已达到 8–12 分钟。

## 镜头与舞台原则

固定等距视角，不旋转地图。镜头只平移和轻微缩放。西角门到院落保持黛玉为视觉中心；室内采用群像建立镜头与轻微推近，避免每句对白都移动镜头。脚底位置使用布局中的格子坐标，不用立绘中心代替。

黛玉入府前段使用 `sedan` 演员组，黛玉步行角色隐藏。到 `flower_gate_stop`，先结束轿子移动，再隐藏演员组、显示黛玉与引路婆子。室内人物开始时暂不揭示，进入院内演出后按节点展示。

## 指令语义示意

以下是早期目标接口示例，不是可直接运行的脚本格式。当前原型已实现 N005–N014，实际类型、演出脚本与执行器见 src/story.ts 和 src/engine.ts；下例中的原文元数据结构仍待正式剧本阶段加入。

```json
{
  "id": "N011",
  "source": {
    "chapter": 3,
    "edition": null,
    "status": "pending_verification"
  },
  "commands": [
    {"type": "move", "actor": "daiyu", "to": "daiyu_greet", "await": true},
    {"type": "move", "actor": "grandmother", "to": "grandmother_greet", "await": true},
    {"type": "pose", "actor": "grandmother", "value": "sad"},
    {"type": "say", "speaker": "narrator", "textType": "adaptation", "text": "黛玉正要行礼，外祖母已迎上前来。"}
  ],
  "next": "N012"
}
```

`move` 在平面逻辑格上寻路，`via` 可指定途经点，默认等待完成。`parallel` 的所有子指令完成后才继续；同一演员不可同时接收两个移动指令。对白必须携带说话者、文本类型、表情与出处状态。

## 跳过、暂停、失败和存档

- 暂停：设置与记录窗口打开时，冻结人物移动、镜头、等待计时和自动播放。
- 跳过：跳过至下一个 `say`，依序应用中间指令的最终状态，取消动画及其旧回调。凤姐未到节点不得提前显示；连续点击不得重复执行命令。
- 存档：在检查点完整记录世界状态和下一节点 ID。对白中可保存最近检查点；若提示“已保存”，须说明保存的是哪个检查点。后续可扩展到每个稳定对白节点。
- 恢复：先重建所有可见人物、位置和屋顶状态，再恢复对白。不能只恢复当前对白而遗漏地图状态。
- 错误：无目标地点、目标被封闭、缺少角色资源时暂停并报告节点 ID；开发阶段不静默传送或吞错。
