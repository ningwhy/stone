# 原著考据与改编规范

## 底本与证据

先取得目标回全文，记录版本、回目、来源地址、取得日期和文字处理方法，保存 `docs/chapterNN-source.txt`。当前前三回参考维基文库，见 [空间考据](../estate-geography.md)。对网页原文先去导航、样式和许可证页脚；不要把搜索摘要或模型记忆当作本回正文。

新增回目需要实际阅读其来源网页或本地底本，不默认后续版本与前三回相同。不得用记忆补写“原文说”。使用外部原文时遵循来源和当前工具的引用限制；正文保存与使用应适用该版本的权利条件。现代注释、地图和影视形象不能直接当作原小说文本。

每个剧情节点保留 `source.chapter`、`source.paragraphLead`、`source.textKind`；目前台词通常是 `adaptation`。新回维护额外证据表 `design/chapterNN-evidence.json`，格式参考 [模板](templates/evidence.json)。证据表是制作资料，当前运行器不会自动读取。

## 四类记录分别写

| 分类 | 写法 | 示例 |
| --- | --- | --- |
| 原文明示 | 保留足以定位的原句和回目 | 出西角门、往东经过荣府正门、入黑油大门 |
| 人物转述或回忆 | 标注讲述者、被讲述时间和地点 | 冷子兴说家族；雨村回忆金陵甄家学生 |
| 解释或推定 | 写明依据、不确定点、其他可行解释 | 西角门具体墙面原文没有明确 |
| 叙事设计 | 写明为游戏落图、转场或尺度作出的选择 | 西墙设角门；回程经正门；相邻房间拆成舞台 |

约束先于坐标：先列“甲在乙东边”“去程必须出某门”“在此没有见到某人”，再决定 40×40 中位置。小说未提供精确距离时，不制造尺寸、地理坐标或唯一复原结论。

## 人物与时间层

每回做人物表：正式 ID、姓名/别称、亲属关系、本回年龄表述、首次实际出场、只是提及、图像复用或新建。年龄有叙述差异时记录矛盾，不强制统一成精确年表。英莲第一回是三岁幼童，不能套用成年香菱立绘。

统一使用这些时间层：`present` 当下、`dream` 梦境、`recollection` 回忆、`reported` 转述。徽标以节点为单位，不代表切一张地图就能消除时间混淆。同一席话提及的家族成员不能自动 `show` 在桌边。

已知案例：顽石和神瑛侍者不要无说明合并为一人；金陵甄家之子与荣府贾宝玉区分；空空道人和跛足道人区分；智通寺老僧与癞头和尚区分。雨村拜贾政书房是另一支行程，黛玉不要跟随；黛玉拜访时贾赦不见、贾政斋戒未见，不得为凑人物互动编成会面。

## 覆盖与文字改编

先按原文顺序做事件清单，再分成可演出的段落、对白节点与行动。每个重要事件、空间转移、人物登场或离场都要能对应节点。诗词与论说可分段或节选、改述，但记录压缩范围；“覆盖本回主要事件”不等于逐字演出。

对白维持人物身份、称谓、信息获知次序和语气，避免把后回真相提前泄露。叙述与角色对白分开，设计解释不要塞进人物嘴里。每段通常保持一屏可读，实际长度以 PC/手机目检为准；不得用缩小字号解决过长台词。

## 地理案例的既定解释

- 列增为东、行增为南。屏幕下方不是正南。
- 第二回“街东宁、街西荣”是金陵旧宅的回忆；第三回京城行程另有文字支持宁东荣西，不能混淆地点。
- 西角门放西墙是用户明确选择；原文未唯一确定墙面。黑油门设南墙偏东，去东院先出西角门、过正门再入黑油门。
- 回程进正门是本版衔接方案，所存第三回底本未明确门名。
- 贾母正房、后房、碧纱橱在总览拆分便于交互，不代表三个独立大院。

发现后续回目的证据与当前图冲突时，先记录冲突并评估整体道路；不能只改一张局部图，却保留相反的总览、指北针和转场路线。

## 考据交付标准

目标回全文可定位；每个关键节点有起句；事件清单能逐项找到节点；身份、年龄、时间层和见面关系检查完成；地点关系有证据或明确标为设计推定。记录仍存争议，禁止用“考证完成”掩盖未核对内容。
