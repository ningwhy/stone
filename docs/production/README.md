## 环境

前端使用 `package-lock.json` 锁定依赖：React 19.3、Phaser 3.90、TypeScript 7、Vite 8。要求 Node ≥22.18；本机用 Node 26.10。`npm ci` → `npm run dev`，默认地址 `http://127.0.0.1:5173`。

地图 JSON 生成通常只需标准 Python；Pillow/numpy 用于抠图后处理、校准和面部合成。本机已验证的解释器：

```sh
/Users/see/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 -c 'import PIL,numpy; print("image dependencies ready")'
```

这是当前机器路径，不是可移植项目依赖。换机器先找已有环境，不默认用系统 Python，不擅自安装 ComfyUI 或模型。ComfyUI 技能只放在项目 `.local-tools`；服务在局域网机器，不在本机。

当前目录没有 Git 元数据。制作前检查实际工作区状态；没有版本控制时，重建前在 `artifacts/backups/` 复制要覆盖的源文件和地图，不用不存在的 Git 回滚承诺恢复。
