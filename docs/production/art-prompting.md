# 生图纪律：母题、验收与落盘

> 适用范围：本项目一切 AI 生图（册页卡片、账簿贴图、人物立绘、家具批次）。
> 上级规范见 [画风、角色与资产生产](art.md)；通用工具纪律见 `.local-tools/local-image-studio/SKILL.md`。
> 来源：账簿贴图四轮迭代（`e124514`、`274d4c6`）与一次返工（本文档记录的那次）。

## 一、核心心法

> **母题里出现的任何名词都会被画出来。**
>
> 风格基底里的否定句权重很低；母题才是被真正渲染的正文。
> 所以「不要什么」写在母题里没用——**要把「不要」的东西从母题里拿掉**。

这是一条贯穿全文的规则。下面所有细则都是它的推论。

## 二、四轮迭代的教训

账簿 14 张贴图走了四轮才合格，每轮暴露一类问题：

| 轮次 | 问题 | 根因 | 修法 |
| --- | --- | --- | --- |
| 一 | 7/11 张出现「裁头人物」 | 母题写「置于案上」，诱出半身人物去摆东西 | 正文写死「无人物、人体、面孔、手臂、衣袍」 |
| 二 | 4 张生图脚本直接崩 | `--keep-old` 下旧图已改名，`dest` 原路径不存在 | 统计实际落盘的那个文件，不是原路径 |
| 三 | 瓶+罐+碗三件套；荒田朽屋里立起巨瓶 | 「古风器物」「静物」是**绘画品类词**，模型照静物范式摆陪衬 | 删掉品类词，风格基底拆成器物/风景两套 |
| 四 | 托盘、碟子、孤灯、茶罐、什物杂陈 | **母题自己写了这些陪衬物** | 从母题里删掉承托物与陪衬，只留主体 |

第四轮最关键：修完母题才发现前一轮的验收清单**本身就漏了一项**——当时只查「零人物 / 无可读文字 / 主体居中」，没查「画面里的器物是否属于这一笔账目」。

> **教训：验收清单也会漏项。清单要逐条对照母题写，不能凭印象列。**

## 三、母题怎么写

### 3.1 不谈品类，只谈「这一件东西」

品类词（器物、静物、古风、美食）自带范式，模型会照范式补齐陪衬。

```
❌ "古风器物：白银与锦缎"          → 银、缎、瓶、罐、碗一起出现
❌ "静物一组：布匹、茶罐、纸包"      → 母题列什么就画什么，还会被补齐
✅ "一锭白银与几枚散碎银角并排散在画面中央，四周一片空白"
```

器物类与风景类要**分开写风格基底**：

| 类别 | 风格基底要点 |
| --- | --- |
| 器物 | 主体占画面大部分，其余完全是空白的宣纸；不画桌子、不画盘子托着它、不添置瓶瓶罐罐 |
| 风景 | 只有自然景物与破败屋舍；不出现任何器物、器皿、人物 |

### 3.2 承托物也是多出来的

「静置**托盘**之上」「置于粗陶**碟**中」「**案**上」——这些词会各自画出一件器物。

即使风格基底写着「不要画盘子托着它」，只要母题写了「托盘」，模型就会画托盘（实测：托盘照画不误）。

**母题只写主体本身，以及主体自身的纹理、颜色、光泽，不写它放在哪儿。**

### 3.3 主体要完整居中

```
✅ "占据画面中央"、"四周一片空白"
✅ "主体完整、居中"
```

「置于案上」让主体被裁或被陪衬挤到边角；「摆在中央」才留得住。

### 3.4 语义要精确到不歧义

| 母题 | 实际画成 | 改法 |
| --- | --- | --- |
| 「半枚鱼符」 | 一条活鱼 | 「刻着一条鱼形纹样的木牌」 |
| 「盖着朱红方印的空白官凭」 | 纸上出现可读红字「怡红院」 | 「一枚小小的方形官印立着」 |
| 「印面刻着简洁的阳文纹样」 | 印面是能读的篆字 | 「朝上的一面是一块完全光素的平面、像未经刻字的素石」 |
| 「印面朝前的一块素石」 | 一块普通方石 | 「顶部雕着一只蜷曲的兽形印钮」 |

「纹样」会被理解成文字，「素石」会被理解成石头——**这类词要换成几何描述**。

### 3.5 负向提示词不可靠

zimage 的 `cfg=1.0`，`--negative` 参数**存在但官方忽略**。只能靠正向正文约束，即：把不该出现的从母题里删掉，而不是加否定句。

## 四、验收清单

每张图逐条对照，**逐条**过，不凭印象：

- [ ] **画面里的每一件东西，都能在母题里找到出处**（含承托物、陪衬）
- [ ] 主体完整、居中，未被裁切、未被陪衬挤到边角
- [ ] 无人物、人体、面孔、手臂、衣袍
- [ ] 无可读文字、拉丁字母、水印、签名；「纹样」处不是能读的字
- [ ] 其余是空白宣纸，没有多出来的桌、案、盘、碟、罐、灯
- [ ] 风格与项目一致（写意水墨、留白、纸纹）
- [ ] 尺寸与落点符合该批次的运行约定

**用拼图审图，不要一张张看。** 14 张各看一遍容易漏；拼成 4×4 网格一眼就能看出哪格多了东西。拼图脚本见下。

```sh
/opt/homebrew/bin/python3 - <<'PY'
import os, glob
from PIL import Image
names = sorted(os.path.basename(p)[:-4] for p in glob.glob('art/cards/source/ledger_*.png')
               if '_v' not in os.path.basename(p))
imgs = [(n, Image.open(f'art/cards/source/{n}.png').convert('RGB').resize((320, 320))) for n in names]
cols = 4; rows = (len(imgs) + cols - 1) // cols
sheet = Image.new('RGB', (cols * 320, rows * 320), (255, 255, 255))
for i, (_, im) in enumerate(imgs):
    sheet.paste(im, ((i % cols) * 320, (i // cols) * 320))
sheet.save('artifacts/ledger-art-sheet.png')
PY
```

> 注意：系统 `python3` 没有 numpy/PIL；用 `/opt/homebrew/bin/python3`。

## 五、落盘与命名

### 5.1 `--keep-old` 有两条落盘路径

```sh
$SCRIPT generate --prompt "..." --name X --keep-old --out DIR
```

| 目标是否已存在 | 结果 |
| --- | --- |
| 已存在 | 旧图改名 `X_v{n}.png`（n 递增），**新图落 `X_new.png`** |
| 不存在 | 直接写 `X.png` |

所以「取最新的一张」**必须按 mtime 排并排除 `_v` 归档**，不能只认 `_new`：

```python
def latest_source(name):
    """--keep-old 有两种落盘路径：目标已存在时旧图改名 _v{n}、新图落 _new；
    目标不存在时直接写原名。所以「最新」要按 mtime 排，不能只认 _new——
    否则第二次重生成时会把上一轮的 _new 当成新图，转出错的 webp。"""
    cands = [c for c in glob.glob(os.path.join(SRC, f"{name}*.png"))
             if "_v" not in os.path.basename(c)]
    if not cands:
        return None
    return max(cands, key=os.path.getmtime)
```

### 5.2 命名归一化

重生成后把生效图**升回规范名**，旧图归档为 `_v{n}`，**零删除**：

```python
src = latest_source(name)          # 生效的那张
canon = f"{name}.png"
if os.path.basename(src) != canon:
    if os.path.exists(canon):      # 旧规范名归档
        k = 1
        while os.path.exists(f"{name}_v{k}.png"): k += 1
        shutil.move(canon, f"{name}_v{k}.png")
    shutil.move(src, canon)
```

`.gitignore` 只忽略 `*_v[0-9]*.png` 与 `_rejected-*/`——**生效图必须入库**，它是权威源。

### 5.3 webp 不能用 MD5 对齐

webp 是有损压缩（q=84），MD5 与 PNG 永远不一致。改用 64×64 灰度像素的 MSE 距离：

```python
def mse(a, b):
    a = np.asarray(Image.open(a).convert('L').resize((64, 64)), dtype=float)
    b = np.asarray(Image.open(b).convert('L').resize((64, 64)), dtype=float)
    return float(np.sqrt(((a - b) ** 2).mean()))
```

阈值 `d < 5` 视为同一张。实测 14 张全部 `d < 0.7`。

对齐时还要在**全部候选**里找最近的那张，确认它就是当前生效图：

```python
cands = sorted((mse(p, tmp), os.path.basename(p)) for p in glob.glob(f"{name}*.png"))
assert cands[0][1] == f"{name}.png", "webp 不是由当前生效图转出的"
```

## 六、串行与队列

- **同一主机单进程串行**；已有队列先等空，绝不清队列、绝不取消他人作业。
- 提交前查 `curl -s http://192.168.4.66:8188/queue`，`queue_running` 与 `queue_pending` 都空才提交。
- `--max-queue-depth 0` 是提交闸门，调用端仍应等待已有任务完成。
- 不要并行增加作业尝试「加速」。曾经并行导致 ComfyUI 进程挂掉、需人工重启。

## 七、报错与判读

| 现象 | 实际原因 |
| --- | --- |
| `FileNotFoundError: dest.stat()` | `--keep-old` 下旧图已改名、`dest` 原路径不存在；统计实际落盘的文件 |
| 生成了但图没变 | `latest_source` 取错了图（只认 `_new`）；按 mtime 取 |
| 线上还是旧图 | 忘了重跑 `npm run art:webp`，或 URL 没有内容版本号 |
| 图里有多余器物 | 母题里写了它——**去改母题，不要加否定句** |

## 八、一句话总结

> 母题是唯一被渲染的正文。写母题时，**每多写一个名词，画面就多一件东西**；
> 风格基底与否定句救不了你，唯一可靠的办法是从母题里把它删掉。
